# LeakShield Pro - One-Minute Exhibition Video Script

**Language:** Roman Urdu + English

**Target duration:** 60 seconds

**Speaking style:** Clear, confident, and natural. Do not speak too fast.

## Recording Plan

| Time | Show on screen | Spoken topic |
|---|---|---|
| 0-6 sec | Shield unlock animation and logo | Introduction |
| 6-16 sec | Main Console | Problem and explanation |
| 16-28 sec | Open Scan, enter an authorized URL, start scan | What it does |
| 28-43 sec | Scan phases, then grouped Findings | How it works and exact evidence |
| 43-52 sec | Learning Mode, fix guide, roadmap | Why it is useful |
| 52-60 sec | Report/Console and project logo | Future scope and closing |

## Exact 60-Second Script

> Assalam-o-Alaikum, this is LeakShield Pro, a completely free and open-source cybersecurity platform. Aaj security tools ko afford aur samajhna difficult hota hai, isi liye humne LeakShield Pro banaya. User apni authorized website URL, code, configuration, ya project folder provide karta hai. Platform security headers, SSL, DNS, technologies, exposed files aur potential secret leaks safely analyze karta hai. Har finding exact affected URL ya file location, redacted evidence, risk level, business impact aur step-by-step fix show karti hai, so developer ko problem ka reason aur solution dono samajh aate hain. Ye passive checks use karta hai, exploit attacks nahi karta, aur Shodan ya paid API require nahi karta. Future mein authenticated testing, team collaboration, GitHub integration aur continuous monitoring add ki jayegi. LeakShield Pro ka mission hai: enterprise-quality cybersecurity, completely free for everyone.

## Delivery Notes

- Start speaking as soon as the shield begins to unlock.
- Pause briefly after saying **LeakShield Pro**.
- While saying **exact affected URL**, point at a finding's evidence section.
- Do not expose a real API key, admin password, or private website during recording.
- Use a website owned by the team or a safe local demonstration target.
- End with the logo and the line: **Enterprise-quality cybersecurity, completely free for everyone.**

- `STEP-BY-STEP FIXES`
